# A Simple Expense Splitter
 
To run this you would need to clone this repository onto your computer. 
Following that you would need to 
 a) Open your bash terminal
 b) run: **cd to/your/folder/path**
 c) run: **mingw32-make** OR** make**
 d) run: **./expense_splitter**
 e) The expense splitter app should now work.
